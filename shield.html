🧠 How ShieldPay Protects Users

The system focuses on explainable pre-payment warnings.

⏱️

1. Before Payment

The safety check occurs when the user presses Pay — before the simulated transaction is allowed.

🔎

2. Signal Detection

The prototype checks urgency, impersonation, OTP requests, suspicious URLs, remote access and unusual payment requests.

💡

Instead of only displaying "SCAM", the system shows the specific signals that triggered the warning.

High-risk payments are blocked in the prototype until the user completes the verification step.
